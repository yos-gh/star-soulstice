# STAR SOULSTICE（仮）— Stage 1 prototype

スターソルジャーのオマージュ STG の 1 ステージ試作（Godot 4.7 / GDScript）。
草案は [docs/drafts.md](docs/drafts.md)。モデル・地形・効果音はすべてコード生成（アセットファイルなし）。

## 起動

`play.bat` をダブルクリック（初回は自動でインポートしてから起動）。

## 操作

| | キーボード | パッド |
|---|---|---|
| 移動 | 矢印 / WASD | D-pad / 左スティック |
| メインショット | Z / Space / `.` | A（ボタン1） |
| スピア + ホーミング | X / Enter / `/` | B（ボタン2） |
| ポーズ / タイトルへ | Esc, P / Q | Start / Back |

## 実装した内容

- **メインショット**: 押すたびに即発射、押しっぱなしで 12 連/秒のオート。直近 1 秒の押下回数から集中ゲージを算出し、秒間 6 回で最大 ×4（オートでは溜まらない）。
- **自機の変形**: Form I（前 2 発）→ II（連射速度・速度 Up、後方 1 発）→ III（前 3way + 後 2way、1 回耐えるシールド。被弾で II に戻る）。
- **スピア**: 前方の短い強力なブレード + 自機周囲のオーラで敵弾消去（重エネルギー弾と体当たりは防げない）。クールタイム 4 秒。
- **ホーミング**: スピアと同時に後方から発射。エネルギー 10 につき 1 発、最大 8 発。タイルは狙わない。
- **エネルギー**: 敵撃破・弾消し（撃破した敵の弾／スピアで消した弾）・タイル破壊で出現。硬いタイルほど多い。
- **敵弾**: 形は共通（球・針）。物理弾＝寒色・中心が暗く輪郭が明るい（撃って壊せる、自機のショットを遮る）、エネルギー弾＝暖色・中心が白く光る（スピアか撃破でしか消えない）。
- **予兆**: 危険な攻撃（破壊不能弾の発射、突進、ラザロの分裂・挟み込み・弾、ボスのエネルギー弾）の前に、攻撃する敵へ「 」が閉じていき（弾は橙、突進や大技は赤、直前に白く点滅）、敵本体が脈打つように光り、突進は進路を点線で示し、短い警告音が鳴る。破壊できる物理弾には予兆なし。
- **アイテム**: 自機に引き寄せる範囲が広く（6.8）、パワーアップも同じく自動回収。エネルギーは回転しない黄色い半透明のワイヤーフレーム立方体。
- **ステージ構成**: 軌道要塞の上空を飛ぶ 3 エリア + ボス。AREA 1 DEBRIS BELT（残骸と漂う小惑星）→ AREA 2 OUTER HULL（装甲甲板・トレンチ・ソーラーアレイ、砲台）→ 開けた宇宙でラザロ → AREA 3 CORE BLOCK（密集した機械区画・リアクター）→ STAR CORTEX。
- **地形**: 要塞の区画（`islandgen.gd`：hull / trench / solar / reactor / fragment / asteroid）に 2×2 の破壊可能ハッチ 3 種（耐久 0.5/1/1.5、硬いほどエネルギーが多い。壊して余った威力で弾が貫通する）。地面は暗く彩度を落とした専用マテリアルで、敵と弾より引っ込んで見える。ボス戦中も区画が流れる（砲台なし）。ショットを吸うので敵に弾が通りにくくなる。まれにスコアスターが隠れている。
- **見た目**: 自機は白×赤×青、敵は金・ブロンズ×ガンメタルに赤い目、地面はティール系の要塞鋼。遠景に環のある惑星と要塞の巨大構造物（被写界深度でぼかし）。
- **敵**: 編隊雑魚 3 種、コンテナ（パワーアップ）、島の砲台、中型機バルワーク、中ボス LAZARO（分裂→包囲→挟み込み）、ボス STAR CORTEX（スターブレインのオマージュ）。
- **早回し**: 15 ウェーブ + ラザロ。ウェーブの敵を一掃するか時間切れで次へ。全ウェーブ後にボス。
- **スコア**: 破壊・タイル・アイテム + クリアタイムボーナス（(260 秒 − クリアタイム) × 1300）。エクステンド 20 万 / 60 万 / 120 万（仮）。

## テスト用オプション

```
Godot_console.exe --path . --fixed-fps 60 -- --autoplay --god --start=6|mid|boss --log --capture=captures --capture-every=3 --quit-after=60 --quit-on-clear --mute
```

見た目の切り分け用に `--hide=sprites,debris,lights,bullets,shots,items,units,player,islands,tiles,rock,turrets,labels,dof,glow,shadow` も使えます。
モデルの確認は `--gallery=1`（自機・敵・アイテム・タイル）、`--gallery=2`（ボス）、`--gallery=3`（地形を順に流す）、`--gallery=4`（自機3形態の拡大）。
